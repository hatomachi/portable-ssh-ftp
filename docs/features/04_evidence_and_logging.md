# 📝 Feature 04: エビデンス即時コピー ＆ 自動ロギング (Evidence & Logging)

> **セッション目的**: 作業報告書やエビデンス作成の負担をゼロにするため、「直前コマンド＋出力のワンクリックMarkdownコピー」と「全入出力の自動ローカルファイル保存」を実装する。

---

## 🎯 このセッションで達成すること
1. **直前コマンドの出力一括コピー（Warp感覚のブロックコピー）**:
   - ターミナル右上に「直前コマンドの出力をコピー」ボタン（またはショートカット `Ctrl+Shift+C`）。
   - プロンプト行〜直前出力までを綺麗に整形してクリップボードにコピー（Markdownコードブロック形式）。
2. **自動ロギング機能（タイムスタンプ付き）**:
   - バックエンド側でセッションごとの全送受信データを `logs/YYYYMMDD_HHmmss_{host}.log` にストリーム保存。
   - 設定で「行頭タイムスタンプ付与」の有効/無効を選択可能。

---

## 🏗️ 変更対象ファイル一覧

### バックエンド (Go)
- `internal/terminal/handler.go` または `internal/ssh/logger.go` [NEW]:
  - PTYストリームのTeeReaderによるローカルファイル保存機能。

### フロントエンド (React / TypeScript)
- `frontend/src/components/Terminal.tsx`:
  - xterm.jsのバッファからアクティブライン／直前コマンドブロックを抽出するコピーユーティリティ。

---

## 🧪 検証シナリオ
1. ターミナルで `df -h` や `systemctl status nginx` などのコマンドを実行。
2. 「直前出力をコピー」ボタンをクリック。
3. クリップボードに整形されたMarkdown形式でコマンドと実行結果が貼り付けられることを確認。
4. `logs/` ディレクトリにタイムスタンプ付きの完全なログファイルが生成されていることを確認。
