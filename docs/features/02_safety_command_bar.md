# 🛡️ Feature 02: セーフティ・コマンドバー＆確認付き送信 (Safe Command Bar)

> **セッション目的**: 本番機での改行コピペ事故・タイポ事故を100%防止するため、送信前編集エリア（スクラッチパッド）と確認付き送信UIを実装する。

---

## 🎯 このセッションで達成すること
1. **ターミナル下部コマンドバー（Command Bar）の実装**:
   - ターミナル直下に常設または開閉（`Ctrl+J` 等）できる入力バー。
   - 手順書から貼り付けた複数行コマンドをプレビュー＆安全に編集。
2. **ステップ実行 / 一括送信モード**:
   - 「一括送信（Send All）」: 確認の上でターミナルへ送信。
   - 「1行ずつ送信（Step Run）」: 複数行の手順を1行ずつ結果を見ながら安全に流し込む。
3. **パラメータ簡易置換（プレースホルダ置換）**:
   - コマンド内に `{{HOST}}` や `<IP>` などの記述があれば、置換用インプットを自動表示して一括置換。

## 🧪 検証シナリオ
1. 手順書から「複数行のコマンド（途中に改行あり）」をコピーしてコマンドバーに貼り付ける。
2. 勝手に実行されず、プレビューエリアに安全に保持されることを確認。
3. 「1行ずつ送信」を押し、1行目のコマンドだけがターミナルに送信されて実行されることを確認。
4. 続けて「次の行」を押すと、2行目が流れることを確認。
