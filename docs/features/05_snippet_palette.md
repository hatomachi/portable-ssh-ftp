# ⚡ Feature 05: パラメータ付きスニペットパレット (Snippet Palette)

> **セッション目的**: 現場で頻出する調査・確認コマンド（監視、ログ検索、ステータス確認）を登録し、プレースホルダを埋めてワンクリックで実行可能にする。

---

## 🎯 このセッションで達成すること
1. **スニペット管理UI**:
   - サイドパネルまたはモーダル（`Ctrl+Shift+P`）で呼び出せるコマンド一覧。
   - カテゴリ別（システム調査、ネットワーク、ログ監視、Docker等）に整理。
2. **パラメータ穴埋め（ダイアログ）**:
   - `journalctl -u {{service}} -n {{lines}} --no-pager` のようなプレースホルダがある場合、入力モーダルを表示して置換。
3. **ローカルJSON保存**:
   - ポータブルに `snippets.json` で定義を読み書き・共有可能。

---

  - よく使うLinux保守・調査コマンドの初期データセット。

---

## 🧪 検証シナリオ
1. スニペットパレットを開き、「サービス状態確認」を選択。
2. サービス名に「nginx」と入力して「実行」を押す。
3. ターミナルに `systemctl status nginx` が送信されて実行される。
